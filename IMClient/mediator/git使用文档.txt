二、临时保存半成品（不想 commit，但要切代码 / 临时实验）
git stash 「临时储物柜」
场景：写到一半，想临时改别的代码，但是不想生成正式 commit

#把当前改动暂时存起来，工作区变干净
git stash
#查看所有暂存的临时储藏（可以存多份）
git stash list
#取出最近一次储藏，恢复代码
git stash pop

只是删掉那次存档，代码还在，可以修改后重新 commit
git reset --soft HEAD~1


git reset --hard 哈希值
